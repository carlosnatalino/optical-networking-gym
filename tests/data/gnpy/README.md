# GNPy example equipment files (test fixtures)

`eqpt_config.json`, `std_medium_gain_advanced_config.json` and
`Juniper-BoosterHG.json` are unmodified copies of the example data shipped with
[GNPy](https://github.com/Telecominfraproject/oopt-gnpy) (`gnpy/example-data`,
commit `e0229c69`, Feb. 2026). They are distributed under GNPy's BSD 3-Clause
License, reproduced in `LICENSE-gnpy`. They are used only to test that the
equipment library parses the real GNPy format.
